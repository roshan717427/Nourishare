# Legal pages (GitHub Pages)

These HTML files are served when GitHub Pages is enabled for this repo.

## Enable hosting

1. Open the GitHub repo → **Settings** → **Pages**.
2. Source: **Deploy from a branch**.
3. Branch: `main`, folder: `/docs`.
4. Save, then wait 1–2 minutes.

## Public URLs

- Privacy: https://roshan717427.github.io/Munchable/legal/privacy.html
- Terms: https://roshan717427.github.io/Munchable/legal/terms.html

App constants live in `config/legal.js`. Update that file if the Pages URL differs.
